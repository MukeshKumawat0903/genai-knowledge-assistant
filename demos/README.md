# Demos

This folder contains demonstration scripts showing how to use various components of the knowledge assistant.

## Available Demos

- **demo_agent_tools.py** - Demonstrates agent tools functionality
- **demo_chain.py** - Shows RAG chain implementation
- **demo_evaluator.py** - Evaluation system examples
- **demo_indexer.py** - Document indexing demonstrations
- **demo_memory.py** - Conversation memory examples
- **demo_retriever.py** - Document retrieval examples
- **demo_ui.py** - UI component demonstrations

## Running Demos

```bash
# Run from project root
python demos/demo_chain.py
python demos/demo_retriever.py
# ... etc
```

Each demo is self-contained and includes mock data where needed to run without full setup.
